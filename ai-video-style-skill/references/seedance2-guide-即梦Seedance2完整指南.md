## §0. Seedance 2.0 vs MiniMax H3 — 关键差异（选模型前先看）

| 维度 | Seedance 2.0（即梦 / 字节） | MiniMax H3（海螺 / MiniMax） |
|---|---|---|
| 平台 | 即梦 App / 网页端为主 | 海螺 App / 网页端 + 公开 API |
| 时长 | 4–15s（文字生成）；支持**视频延长** | 4–15s |
| 最大分辨率 | **≤720p**（834×1112，约 0.93M 像素） | 768p / **1440p（官方推荐）** |
| 图片输入 | jpeg/png/webp/bmp/tiff/gif，≤9 张，<30MB | 图≤9（256–5760px） |
| 视频输入 | mp4/mov，≤3 段，单段 [2,15]s，<50MB | 视频≤3（2–15s） |
| 音频输入 | mp3/wav，≤3 段，总≤15s，<15MB | 音频≤3（需配图/视频） |
| 混合上限 | **≤12 文件** | ≤12 文件 |
| 声音 | 自带音效/配乐（需描述触发） | **原生双声道**（所有结果默认带声） |
| 入口 | **首尾帧** + **全能参考**；「智能多帧 / 主体参考」不可选 | 首尾帧 + 全能参考 + 多模态融合 |
| **合规红线** | **禁止上传写实真人脸素材**（图片/视频均拦截） | 无此硬限制（含人脸参考图可用） |
| 标志性能力 | 视频**编辑/延长/角色替换/剧情颠覆**、一镜到底、卡点 | 多模态融合、音色克隆、精准局部编辑、1440p |
| 标注体系 | `@图片1 / @视频1 / @音频1` 自然语言 | `@图片1 / @视频1 / @音频1` 自然语言（同体系） |

**一句话选型**：要**改已有视频**（换人/换景/颠覆剧情/延长）、做**一镜到底/卡点**、且**不追求超高分辨率**→ Seedance 2.0；要**纯文字多模态融合**、**1440p 高清**、**音色克隆/双声道原生音频**、含写实人脸参考 → MiniMax H3。

# Part A — 即梦 App 端 `@` 自然语言写法

Seedance 2.0 用 `@素材名` 指定每个图片/视频/音频的用途。交互入口：**首尾帧**（只传首帧图+prompt）或**全能参考**（图/视频/音频/文本任意组合）。

## A1. 完整公式（三段式，与 H3 同构）

```
参考素材说明  +  核心创意  +  画面过程说明
(哪个 @素材 当什么)  (主体+地点+事件+风格+运镜)  (按 shot 分段、情绪/时序/节奏)
```

- **参考素材说明**：明确每个 `@图片N / @视频N / @音频N` 的用途（首帧？人物参考？运镜参考？配乐？）。素材多时务必逐个 `@` 标清，别把图/视频/角色搞混。
- **核心创意**：主体是谁、在哪、发生什么、什么风格、什么运镜。
- **画面过程说明**：按时间轴分段写（0–5s / 6–11s / 12–15s），每段写清情绪、动作、镜头、声音。

## A2. `@` 标注 13 类（提炼自官方 15 个 Case）

| # | 标注写法 | 用途 | 案例 |
|---|---|---|---|
| 1 | `@图1 作为首帧` | 首帧锚定（首尾帧入口） | 油烟机广告首帧 |
| 2 | `@图片1 角色/人物参考` | 锁定人物/角色外观 | 驴骑摩托、女将军 |
| 3 | `@图片X 服装/武器/包参考` | 服装、道具、物件一致 | 女将军武器、换装海报 |
| 4 | `@图片X 场景参考` | 场景/环境外观 | 电梯外场景、像素世界 |
| 5 | `@视频1 参考运镜` | 复刻镜头语言（希区柯克变焦/环绕/跟随） | Case 4 电梯运镜 |
| 6 | `@视频1 参考动作` | 复刻具体动作/表演 | 崩溃大叫、打斗 |
| 7 | `@视频1 参考转场` | 复刻转场/一镜到底逻辑 | Case 2 棋局→沙滩→窗帘 |
| 8 | `@视频1 参考节奏` | 复刻剪辑节奏 / 卡点 | 广告分镜、卡点 |
| 9 | `@视频1/@音频1 参考音效/BGM` | 复用声音设计 | Case 8 鱼眼镜头音效 |
| 10 | `用XX风格和音色，将@图片1演绎出来` | 台词/音色 + 剧情演绎 | Case 9 悟空科普 |
| 11 | `将@视频1的人物换成@图片1` | **编辑·角色替换** | Case 5 换脸+主观视角 |
| 12 | `颠覆@视频1里的剧情` / `颠覆@视频1的整个剧情` | **编辑·剧情颠覆** | Case 12 桥上推人 |
| 13 | `将@视频1延长 Ns` | **编辑·视频延长** | Case 7 延长15s补广告 |

**铁律**：
- 想锁脸/锁角色 → 必传图并标「@图片N 人物参考」，且**不要用写实真人脸**（合规拦截）。
- 想复刻运镜/动作 → 传参考视频并写「参考@视频1 的运镜/动作」，无需写一堆细节。
- 编辑已有视频 → 用 `将@视频1的XX换成@图片N` / `颠覆@视频1剧情` 句式，明确「改什么 + 保留什么」。
- 延长视频 → 生成时长选「新增部分」时长（延长 5s 就选 5s）。

## A3. 核心创意 5 要素（与 H3 同）

主体（谁）+ 地点（哪）+ 事件（做什么）+ 风格（什么调性）+ 运镜（怎么拍）。
运镜词表（提炼自 Case）：希区柯克变焦、环绕镜头、跟随镜头、侧面跟拍、俯拍、仰拍、镜头前推/拉远、向左/右摇镜头、固定镜头、低空飞过、穿梭、特写/面部特写、一镜到底追踪。

## A4. 画面过程说明（按 shot 分段）

- 每段标注 **时间轴 + 情绪 + 动作 + 镜头 + 声音**，如：`0–5s 主体好奇试探（情绪：放松）；6–11s 沐浴露涂抹（情绪：惬意），穿插眯眼特写；12–15s 甩毛（情绪：满足）`。
- **台词/字幕必须写原文**：如成片字幕「宜口可乐，不可不尝！」、广告语遮罩「Inspire Creativity, Enrich Life」要原样写出。
- **跨 shot 连续性**：动画/动作从 A 过渡到 B 写「保持连贯流畅」，一镜到底写清场景切换逻辑（棋局→沙砾→沙滩→窗帘无缝渐变）。

## A5. 三类模式写法

1. **多模态素材融合（全能参考）**：图+视频+音频+文本任意组合，逐个 `@` 标用途。例：@图1 首帧 + @视频1 运镜 + @视频3 音效。
2. **图生视频（首尾帧）**：只传首帧图 + prompt 走首尾帧入口；传首+尾帧两图即首→尾，不自动切镜。
3. **纯文字**：无素材时更具体——大全景+中景+特写分层，情绪/时序/运镜写满。

## A6. 避坑

| 坑 | 解法 |
|---|---|
| 素材用途没标清，图/视频/角色搞混 | 每个 `@素材` 都写明「当什么」 |
| 上传写实真人脸 → 被拦截无法生成 | 改用非写实/风格化人脸，或仅用参考视频 |
| 延长视频时生成时长选错 | 延长 Ns 就选 Ns（新增部分时长） |
| 想复刻运镜却写一堆细节 prompt | 直接传参考视频 + 「参考@视频1 运镜」 |
| 编辑时没说保留什么 → 整段被改 | 写明「改 XX，其余保持不变」 |
| 智能多帧 / 主体参考入口找不到 | Seedance 2.0 这两个入口**不可选**，用首尾帧/全能参考 |

## A7. 真实示例（4 个，提炼自官方 Case）

**示例 1 — 视频编辑·角色替换 + 主观视角（Case 5）**
```
将@视频1的人物换成@图片1，@图片1为首帧，人物带上虚拟科幻眼镜，
参考@视频1的运镜及近的环绕镜头，从第三人称视角变成人物的主观视角，
在AI虚拟眼镜中穿梭，来到@图片2的深邃蓝色宇宙（飞船穿梭），
镜头跟随飞船穿梭到@图片3的像素世界（低空飞过像素山林），
视角仰拍急速穿梭到@图片4的浅绿色纹理星球（掠过表面）。
```
套路：编辑句式 `将@视频1人物换成@图片1` + 首帧锚定 + 多图分场景 + 运镜串联。

**示例 2 — 剧情颠覆（Case 12）**
```
颠覆@视频1里的剧情，男人眼神从温柔瞬间转为冰冷狠厉，
在女主毫无防备的瞬间猛地将女主从桥上往外推，动作干脆利落、蓄谋已久，
女主坠水瞬间没有尖叫只有难以置信的眼神，抬头嘶吼：“你从一开始就在骗我！”
男主阴冷低声：“这是你欠我家族的。”
```
套路：编辑句式 `颠覆@视频1剧情` + 情绪反转 + 台词原文 + 镜头/表演指令。

**示例 3 — 视频延长 + 分镜广告（Case 7）**
```
延长15s视频，参考@图片1、@图片2的驴骑摩托车形象，补充一段脑洞广告：
画面1：侧面固定镜头，驴冲出棚栏，鸡受惊；
画面2：沙地盘旋，先特写轮胎再切半空俯拍盘旋特技掀烟雾；
画面3：雪山背景，驴飞越山坡，广告语遮罩「Inspire Creativity, Enrich Life」，扬起尘烟。
```
套路：延长句式 + 多画面分镜（固定/特写/俯拍）+ 广告语原文遮罩。

**示例 4 — 一镜到底追踪（Case 11）**
```
@图片1@图片2@图片3@图片4@图片5，一镜到底的追踪镜头，
从街头跟随跑步者上楼梯、穿过走廊、进入屋顶，最终俯瞰城市。
```
套路：多图作为沿途场景锚点 + `一镜到底` + 连续空间路径描述。

## A8. 参数速查

- **时长**：文字生成 4–15s 自由选；视频延长按「新增部分」时长。
- **图片**：jpeg/png/webp/bmp/tiff/gif，≤9 张，每张 <30MB。
- **视频**：mp4/mov，≤3 段，单段 [2,15]s，每段 <50MB；总像素上限约 720p（834×1112）。
- **音频**：mp3/wav，≤3 段，总 ≤15s，<15MB。
- **混合**：图+视频+音频 总文件数 **≤12**；建议优先上传对画面/节奏影响最大的素材。
- **声音输出**：自带音效/配乐（靠 prompt 描述触发，如「搭配轻快治愈 BGM」「环境音：走路声/人群声」）。
- **合规**：**禁止写实真人脸素材**（图片/视频均拦截）。
- **入口**：首尾帧 / 全能参考（智能多帧、主体参考不可选）。

# Part B — 能力 × 提示词映射（10 大能力）

手册把 Seedance 2.0 的升级拆成 10 大能力，每条对应一种写法：

| 能力 | 提示词写法要点 | 见 Case |
|---|---|---|
| 一致性提升（人脸/服装/字体） | 传参考图 + `@图片N 人物/服装参考`；字体/小字写清原文 | 基础 Case |
| 运镜/动作精准复刻 | 传参考视频 + `参考@视频1 运镜/动作`；无需堆细节 | Case 4 |
| 创意模版/复杂特效复刻 | `参考@视频1 节奏和运镜，@图1 角色造型` | Case 5/6 |
| 创意性/剧情补全 | 给图/视频 + `用XX风格和音色将@图片1演绎出来` | Case 9 |
| 视频延长 | `将@视频1延长 Ns`（生成时长选 Ns） | Case 7 |
| 音色更准/声音更真 | `用XX风格和音色`；或 `BGM参考@视频3音效` | Case 8/9 |
| 一镜到底/镜头连贯 | `一镜到底` + 场景无缝渐变逻辑 | Case 2/11 |
| 视频编辑可用度高 | `将@视频1的XX换成@图片N` / `颠覆@视频1剧情` | Case 5/12 |
| 音乐卡点 | 分镜对齐节拍 + `参考@视频1节奏` | Case 7/8 |
| 情绪演绎更好 | 写清情绪词 + 面部/肢体指令（`崩溃大叫，参考@视频1`） | Case 14 |

## C1–C15 精选深度拆解（绑定 Part A/B 规则）

**C4 电梯运镜复刻**【原文】`参考@图1的男人形象，他在@图2的电梯中，完全参考@视频1的所有运镜效果还有主角的面部表情，主角惊恐时希区柯克变焦，几个环绕镜头展示电梯内视角…`【拆解】图1锁角色 + 图2锁场景 + 视频1复刻运镜与表情；`希区柯克变焦`/`环绕镜头` 直接点名运镜词（A3 词表）。【套路】「参考视频运镜 + 点名具体运镜技法」比纯描述更准。

**C5 换脸+主观视角**【原文】`将@视频1的人物换成@图片1，@图片1为首帧，人物带虚拟科幻眼镜，参考@视频1运镜及环绕镜头，从第三人称变主观视角，穿梭到@图片2宇宙…@图片3像素世界…@图片4星球`【拆解】编辑句式（A2#11）+ 首帧锚定（A2#1）+ 多图分场景（A2#4）+ 运镜串联（A3）。【套路】「编辑换人」与「多图空间穿梭」可叠加。

**C7 延长广告**【原文】`延长15s视频，参考@图片1@图片2驴骑摩托形象，补充脑洞广告：画面1侧面固定…画面2沙地盘旋特写轮胎…画面3雪山飞越+广告语遮罩"Inspire Creativity,Enrich Life"`【拆解】延长句式（A2#13）+ 多画面分镜 + 广告语原文遮罩（A4）。【套路】延长 = 新增分镜续写，时长选新增段。

**C9 科普剧情补全**【原文】`用科普风格和音色，将图片1中的内容演绎出来，内容包括悟空借芭蕉扇…铁扇公主不肯借扇还欲报仇…争执小故事讲解`【拆解】音色/风格指令（A2#10）+ 给图让模型补全剧情。【套路】「风格+音色+图」触发剧情演绎，无需参考视频。

**C12 剧情颠覆**【原文】`颠覆@视频1里的剧情，男人眼神温柔转冰冷，猛推女主下水…女主嘶吼"你从一开始就在骗我！"男主阴冷："这是你欠我家族的。"`【拆解】编辑句式（A2#12）+ 情绪反转 + 台词原文（A4）。【套路】颠覆剧情 = 改人物设定 + 保留原场景 + 台词原文。

**C14 情绪演绎**【原文】`@图片1女子走到镜前，姿势参考@图片2，沉思后突然崩溃大叫，抓镜子动作和情绪完全参考@视频1`【拆解】图2锁姿势 + 视频1复刻情绪/动作（A2#6/B情绪）。【套路】情绪戏 = 参考视频的「情绪+肢体」+ 文字强化。

## §3. 与 MiniMax H3 的范式互通

- **`@` 标注体系互通**：Seedance 2.0 与 H3（海螺 App）都用 `@图片N/@视频N/@音频N` 自然语言标注，13 类用法大部分重合；差异在 Seedance 多了「编辑类」（换人/颠覆剧情/延长），H3 多了「音色克隆/全参考结构化字段」。
- **选模型**：见 §0 对照表——编辑已有视频/一镜到底/卡点/不追求高清 → Seedance 2.0；纯文字多模态融合/1440p/双声道原生音频/含写实人脸 → H3。
- **合规**：Seedance 2.0 **禁写实真人脸**；H3 无此限制。混用时注意素材合规。
