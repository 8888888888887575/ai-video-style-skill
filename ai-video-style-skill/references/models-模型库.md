> 数据基于 2026 年公开评测与厂商规格（截至 2026-08）。价格/时长会随版本迭代变动，使用本 skill 时以各模型当前官网为准。
> 用途：配合 `styles.md` 与 `decision-matrix.md`，在收到创意简报时给出「用哪个模型 + 为什么」。
> 标注：★ = 该维度强；☆ = 中等；△ = 弱/不擅长。

## 分维度细评

### Seedance 2.0（字节）
- ★ 动物理/布料/人体运动理解强；角色跨帧一致性好。
- ★ 提示词遵循度高；Fast 档极便宜（$0.022/s）。
- ☆ 最长仅 8s；无原生音频；无 4K。
- 适合：批量生产、产品视频、动态内容初稿。先它探 10 个方向，再用 Veo/Sora 出终稿是成熟工作流。

### Kling 3.0 / Video O03（快手）
- ★ 人体运动真实（头发飘、布料垂坠正确）；3.0 支持原生音频；O03 视觉保真度 2026 顶级。
- ★ 复杂场景（多主体、反射、大气效果）连贯性好；长片（10s）时序一致性强。
- ☆ 价格中高；手部/手指偶有伪影；生成较慢（O03 约 2 分钟）。
- 适合：产品/商业片、社媒、对时长+声音都有要求的营销资产。

### Veo 3.1（Google DeepMind）
- ★ 电影级写实、接近实拍素材质感；原生音频同步**业界最佳**（对白/环境音/音乐同扩散过程生成）。
- ★ 光影、景深、调色出色；提示词遵循强。
- ☆ 仅 8s；快运动序列偶有不一致；社区 prompt 资源较少。
- 适合：电影感内容、HD 制作、需要音画一体的场景。

### Sora 2（OpenAI）
- ★ 叙事/剧情向理解强；时序连贯与物理（因果、液体）强；最长可达 20s；构图有「导演意图」。
- ☆ 无原生音频；生成慢（~90s）；可用性偶有容量限制。
- 适合：叙事短片、电影序列、需要长镜头与创意构图的专案。

### MiniMax H3（MiniMax）
- ★ **多模态联合参考业界第一梯队**：图(≤9张,256–5760px) / 视频(≤3段,2–15s) / 音频(≤3段，需配图或视频) 自由组合，**混合≤12 文件**；支持「首帧/尾帧」与「全能参考」两种模式，可单点锁脸/锁动作/锁场景。
- ★ **精准编辑**：角色/物体替换、背景/光影替换、台词/音色修改、高精度局部指令遵循（一句只改一个局部而不动全画面）。
- ★ **原生双声道音频**：所有结果默认带声；对白+音效+配乐一体；TTS 精准覆盖 **11 种语言**（中/英/日/韩/法/德/西等），**音色克隆与迁移**质量高，动漫向口型稳。
- ★ **时长与画质**：单条 4–15s；分辨率 768p(短边768)/**1440p（官方推荐）**；24FPS；商用全场景（MG/动漫/写实/产品均可打）。
- ★ **提示词三段式范式**：`参考素材说明 + 核心创意 + 画面过程说明`，用 `@图片1/@视频1/@音频1` 标注素材用途；三类生视频入口——①多模态素材融合 ②图生视频(1张=首或尾帧,2张=首+尾帧不自动切镜) ③纯文字(需大全景+中景+特写分层)。详见 `prompt-templates.md 模板 K`、决策矩阵 Q14。
- ☆ 纯写实巅峰略逊 Veo 3.1 / Kling O03；1440p 出图更慢、成本更高。
- 适合：需要上传参考图/视频/音频做角色或场景锁定、需要精准改局部、需要带声/换音色、以及 MG/动漫/多语种口型的全场景商用内容。

### Vidu Q3（生数科技）
- ★ **非写实/anime 一致性最强之一**；多输入架构（文+图+首尾帧同程）；原生音频；性价比高（12–16s @ $0.07）。
- ☆ 细节弱于 Veo/Sora/Kling 顶级；社区资源较少。
- 适合：anime、插画风、需要首尾帧精确控制镜头起止的创作者。

### Wan 2.7（阿里通义）
- ★ **开源可自部署**（免费本地跑）；I2V 强；**首尾帧 / R2V / 思考模式**（先规划再生成，复杂提示遵循好）；**屏内可读文字（12 国语言）**；风格化/艺术好。
- ☆ 无 4K；本地需强 GPU。
- 适合：风格化、产品营销（首尾帧锁产品落帧）、需要屏内文字、隐私/自托管场景。

### Runway Gen-4 / 4.5
- ★ **运镜控制、运动笔刷（motion brush）、video-to-video、资产管理**行业最佳；对 prompt 内运镜指令响应好。
- ☆ 成本高；首尾帧/R2V/音频 I2V 多锁 Pro；写实巅峰略逊 Veo/Sora。
- 适合：导演向、需要精确控制某区域运动、agency 工作流。

### PixVerse v5.6 / v6
- ★ **风格化/非写实强**（动漫、卡通、插画、夸张比例）；竖屏社媒友好；快、低成本。
- ☆ 写实弱；无原生音频；偏利基。
- 适合：动漫/游戏/文化特定视觉、TikTok/Reels/Shorts 批量。

### Luma Ray 3 / Dream Machine
- ★ 产品/物体内容强；输出干净无伪影；I2V 快。
- ☆ 仅 5s；中价；无音频；特色不鲜明。
- 适合：快速迭代、产品向内容。

### Pika 2.0
- ★ 界面最简、特效有趣、prompt 实验友好；社区历史长。
- ☆ 巅峰质量不及头部；偏实验。
- 适合：新手探索、实验短片。

### Animora / MotionVid
- ★ **MG 动态图形 / 动画赛道专精**（intro、解释器、logo 动画）；大多数电影级模型在此反而弱。
- ☆ 非动画/写实不是其长。
- 适合：YouTuber intro、课程解释器、营销产品 promo、MG。

### HappyHorse 1.1（阿里淘天）
- ★ 动漫/卡通审美强；**7 国语言口型（含演唱）**；15s 1080p 多镜头；匿名发布后登顶竞技场。
- ☆ 无 4K；控制功能少于 Veo/Seedance；无参考图系统。
- 适合：动漫、角色口播、多镜头序列。

### LTX 2.3（Lightricks，开源）
- ★ 开源、最高 4K@50fps、20s、原生竖屏；fp8 约 18GB 显存可消费级跑。
- ☆ 时序偶不稳定/glitch。
- 适合：高分辨率自部署、数字标牌。

### 数字人专线（Hedra / HeyGen / Synthesia）
- 与「通用 T2V」不同类：解决发言人/培训/多语品牌视频。戏剧角色用 Hedra/Higgsfield，企业口播用 HeyGen/Synthesia。

## 叙事 / AI 漫剧工作流补充（来自 NeoWoW neo-tv 创作者范式）

neo-tv 上的优秀创作者作品显示，**AI 漫剧 / AI 短剧**（国风玄幻、科幻末日、都市言情、音乐 MV）是当下最主流品类。这类需求的关键不是「单条风格」，而是**跨镜头角色 / 世界观一致**与**多镜头叙事**。

- **一致性机制**：优先用支持首尾帧 / 角色锁定的模型——Wan 2.7（首尾帧 + 思考模式）、Vidu Q3（首尾帧 + 多输入）、Seedance 2.0、Kling 3.0。
- **工作流**：建「角色表 + 场景表」作为固定参考 → 拆 shot list → 逐镜生成（必要时叠 Veo 3.1 / Sora 2 提电影感）→ 剪辑拼接。
- **平台**：NeoWoW 等「画布 / 角色锁定」工具适合先搭骨架，再导出到上述模型逐镜渲染。
- 详见 `styles.md §5`、`prompt-templates.md 模板 E`、`decision-matrix.md` 的 AI 漫剧分支。

## AIX Studio 创作者范式补充（来自 aix.studio 工作流库）

AIX Studio 是中文区头部「专业 AI 视频创作 + 工作流分享」平台，其工作流库暴露了当下最卷、也最商业化的几类需求，是 NeoWoW neo-tv（偏叙事漫剧）之外的重要补充：

### ① 商业 / 电商 / 产品视频（条目最多）
- 工作流示例：商业首尾帧视频、商业单图生视频、商业级万物迁移、珠宝设计改款、珠宝饰品光影合成、鞋类上脚、电商模特换装 + 多姿势、品牌宣发 TVC-25 宫格、4A 级品牌屋、亚马逊品牌 A+ 详情页。
- 模型：产品落帧与屏内文字用 **Wan 2.7**；批量/物理用 **Seedance 2.0**；保真/商业用 **Kling O03**；产品干净用 **Luma Ray 3**；汽车/大片用 **Veo 3.1 / Sora 2**。
- 提示词要点：真实材质（`no plastic`）、干净打光、参考图 + 首尾帧锁姿态。详见 `styles.md §9` / `prompt-templates.md 模板 F`。

### ② 建筑 / 室内写实渲染
- 工作流示例：建筑草图风格渲染、装修效果图、建筑效果图变换季节、室内住宅平面转图纸、室内房间光线氛围、光追设计、毛坯图生成效果图。
- 模型：写实建筑用 **Veo 3.1 / Sora 2 / Seedance / Kling O03**；草图转写实 I2V 用 **Wan 2.7 / Luma**。详见 `styles.md §10` / `模板 G`。

### ③ 写真 / 人像摄影流派
- 工作流示例：厚涂脸（女/男）、黑红高端写真复刻、Y2K 千禧街头、儿童写真、婚纱照背景光影合成、萌宠写真馆、雾凇冷白光、窗台薄纱光、丁达尔光影。
- 模型：写实人像 **Veo/Kling/Seedance**；厚涂/插画 **MiniMax H3/Vidu/Wan**。详见 `styles.md §11` / `模板 H`。

### ④ CG 漫剧 / 命名美学 / 剧本分镜
- **CG 漫剧**：AIX 单列「专业影视级 CG 漫剧分镜」「精品漫剧角色资产库」，确认 CG 漫剧（3D 三渲二）是独立子类，区别于 2D 漫剧（见 `styles.md §5` 技术专题 1）。
- **命名美学锚定**：胡金铨中式美学 / 国画转胡金铨风格等高频工作流，揭示「用导演/流派视觉签名锚定美术方向」的高复用技巧（见 `styles.md §5` 技术专题 2）。
- **剧本分镜 / 角色+剧本直出 / 爆款复刻**：AIX 的「全自动剧本分镜」与 NeoWoW 的「画布/角色锁定」本质是同一套生产链（见 `styles.md §12`）。

> 注：部分聚合平台（如 axstudio.ai）列出的模型版本（Kling 2.5、Wan 2.6）与本矩阵（Kling 3.0/O03、Wan 2.7）存在差异，属不同来源/时点口径；本 skill 以 2026-08 评测共识为准，实际选型以各模型官网当前版本为准。
