# 02 · CG — Computer Graphics（三维渲染 / 3D CGI）

> **一句话定位**：用三维管线「渲染」出来的画面，而非拍出来的。核心卖点是 **材质可信度 + 光照物理 + 模拟（流体/破碎/布料）+ 电影级运镜**。
>
> **两条路线**：
> - **写实 CG（Photoreal CG）**：PBR 材质、GI/光追、SSS 皮肤，目标接近实拍但比实拍更干净可控。
> - **风格化 CG（Stylized / Toon 3D）**：三渲二、Pixar 风、Arcane 手绘感 3D，目标是「3D 的体积 + 2D 的美术」。
>
> **与相邻风格的边界**：与 PV 区别在于 CG 的运动由**物理**驱动而非节拍；与手绘 2D 是**对立管线**（禁止混写）；与建筑渲染区别在于 CG 更强调角色/生物/模拟。
>
> **装配顺序**：01 → 02 → 03 →(04)→ 05 → 06 →(07)→ 08 →(09/10/11)→ 12 → 13 → 14。

## 00 范例（Examples · 完整英文 prompt）

> 结构 = 场景主语 + 动作 + 镜头 + 光影 + 风格 + 材质 + 后期 + 负向。中文为注释，投喂前删除。

### 例 1 · 写实 CG 生物特写（PBR + SSS）
```
A photoreal CG dragon hatchling curls on a wet obsidian rock and slowly opens one eye,   // 主体+动作
its wet scales shifting as it breathes, membrane wings twitching with secondary motion,  // 次级运动
macro close-up, 85mm, slow gimbal push-in with shallow depth of field,                   // 镜头

--no cartoon, cel shading, flat lighting, plastic look, melting geometry, extra limbs    // 负向
```

## 02 景别构图（Shot Size / Angle / Lens / Rig）· 必选

### 景别词库
- `extreme wide establishing` — 极远景建立镜（展示规模）
- `wide shot` / `medium full shot` / `medium shot`
- `close-up` / `extreme macro close-up` — 微距（材质展示核心）
- `insert detail shot` — 局部细节插入（齿轮、铆钉、鳞片）
- `hero turntable framing` — 环绕展示构图
- `scale-comparison shot` — 对比参照物体现体量

### 角度词库
- `low-angle heroic` — 仰角，体量与压迫
- `eye-level neutral` — 平视中性
- `high-angle overview` — 俯瞰
- `top-down orthographic feel` — 近正交俯视（设计感）
- `worm's eye through foreground geometry` — 贴地穿前景
- `dutch tilt`（慎用，写实 CG 里易显廉价）

### 虚拟摄影机 / 设备词库
- `virtual camera with real lens physics` — 带真实镜头物理的虚拟机
- `gimbal smooth dolly` — 稳定器推轨
- `technocrane arc` — 电影摇臂弧线
- `drone flythrough` — 无人机穿越
- `motion-control repeatable move` — 运动控制可重复轨迹（产品片）
- `handheld simulation with subtle noise` — 模拟手持（给 CG 加真实感）
- `locked-off tripod` — 定机位

### 焦段 / 光学词库
- `18mm ultra-wide with barrel distortion` — 超广（穿越镜）
- `35mm / 50mm / 85mm`
- `100mm macro lens` — 微距（材质/产品）
- `200mm telephoto compression` — 长焦压缩（远景层次）
- `anamorphic 2.39:1 with oval bokeh` — 变形宽银幕
- `shallow depth of field, f/1.8` / `deep focus, f/11`
- `physically accurate lens flare` / `slight chromatic aberration`

### 构图词库
- `depth layering: foreground / midground / background` — 三层纵深（CG 最重要的构图法）
- `atmospheric perspective haze` — 空气透视分层
- `leading lines from architecture` / `symmetry with vanishing point`
- `negative space to emphasize scale` / `silhouette read first`

### 速查表：目标 → 镜头配方

| 目标 | 景别 | 焦段 | 机位运动 | 景深 |
|---|---|---|---|---|
| 展示材质 | extreme macro | 100mm macro | 慢滑轨 | 极浅 f/1.8 |
| 展示体量 | EWS + 参照物 | 18–24mm | drone 升 | 深 f/11 |
| 角色表演 | MCU | 50–85mm | 微手持 | 浅 |
| 产品 hero | 中景 turntable | 85–100mm | motion control | 中 |
| 空间穿越 | 移动广角 | 18mm | drone flythrough | 深 |
| 模拟展示 | 全景 | 35mm | 定机位 | 深（要看清模拟） |

### 联动规则（重要）
- **微距 + 大运动 = 崩**：100mm macro 只配极慢机位移动，否则景深内容量不足会糊。
- **深景深 + 复杂几何 = 拓扑翻车**：全画面清晰会暴露模型融化；复杂场景请用 `shallow depth of field` 掩护。
- **写实 CG 必须写镜头物理**：`physically accurate lens, natural falloff`，否则模型输出「游戏截图感」。
- **运动快 → 快门优先**：高速运动写 `high shutter speed, crisp frames`；慢镜写 `180-degree shutter motion blur`。
- **一镜到底越长越危险**：>5s 的 flythrough 请拆段或选 Sora 2（时序连贯最强）。

- `quadruped creature with accurate anatomy` — 四足生物解剖正确

- `humanoid robot with visible joint mechanics` — 关节机构外露机器人
- `digital double of a real actor` — 数字替身

### 硬表面 / 物体词库
- `hard-surface mecha with sharp bevels and panel lines` — 倒角与分模线
- `industrial machinery with functional parts` — 功能可信的机械
- `sci-fi vehicle with visible thrusters` — 带推进器载具
- `architectural megastructure` — 巨构建筑
- `consumer product with brand-clean geometry` — 商业产品几何

### 解剖 / 拓扑质量词库（防崩关键）
- `clean topology, consistent edge flow` — 干净拓扑
- `solid geometry, no melting, no interpenetration` — 实体不融化不穿模
- `anatomically correct joints and weight distribution` — 关节与重心正确
- `consistent scale and proportion across the shot` — 全镜比例一致
- `symmetrical where it should be, asymmetric detail elsewhere`

### 体型 / 体量词库
- `massive scale, dwarfing the environment` — 巨大体量
- `compact and agile silhouette` — 紧凑敏捷剪影
- `heavy mass with visible inertia` — 重质量带惯性
- `delicate and lightweight` — 轻盈

### 联动规则
- 写实 CG 角色 **必须**带 `clean topology, solid geometry, no melting` —— 这是 CG 风格最高频翻车点。
- `photoreal humanoid` 尽量避开手部特写；必须拍手时加 `five fingers, anatomically correct hand`，并准备后期修。
- 体量感靠**参照物 + 慢速运动 + 广角低机位**三件套，只写 `massive` 无效。

## 05 光影氛围（Lighting & Mood）· 必选

### 布光技法词库
- `single soft key with large area light` — 大面积柔主光
- `three-point studio lighting (key / fill / rim)` — 经典三点
- `HDRI environment lighting` — HDR 环境球照明
- `global illumination with color bleeding` — GI 带颜色渗透
- `ambient occlusion in crevices` — 缝隙 AO
- `ray-traced reflections and shadows` — 光追反射与阴影
- `volumetric light shafts (god rays)` — 体积光柱
- `practical lights inside the scene` — 场景内实光源
- `caustics from glass and water` — 焦散
- `area light strip for edge definition` — 条形光勾边（产品）
- `overcast softbox sky` — 阴天大柔光
- `hard sun with crisp shadows` — 硬日光
- `emissive geometry as light source` — 自发光几何当光源
- `two-tone hard cel shadow`（仅三渲二）

### 色温 × 情绪速查表

| 色温 / 配色 | 英文 tag | 情绪 | 典型场景 |
|---|---|---|---|
| 5600K 中性日光 | `neutral daylight, accurate white balance` | 客观、真实 | 产品 / 数字替身 |
| 3200K 钨丝暖 | `warm tungsten interior` | 亲密、复古 | 室内表演 |
| 7500K 冷阴天 | `overcast cool daylight` | 阴郁、纪实 | 写实生物 |
| 橙×青 | `orange and teal cinematic grade` | 大片感 | 科幻/动作 |
| 冷蓝单色 | `moonlit blue monochrome` | 神秘、夜 | 潜行/深海 |
| 红橙火光 | `firelight flicker, warm bounce` | 危险、原始 | 火山/战场 |
| 品红青霓虹 | `neon magenta and cyan practicals` | 赛博 | 科幻都市 |
| 纯白无影 | `clean white void, seamless cyclorama` | 商业、干净 | 产品/概念 |

### 组合公式
```
[主光类型+方向] + [填充/GI] + [轮廓/边缘光] + [氛围介质] + [反射环境]
例：single soft key from upper-left + GI bounce from warm floor + cyan rim from背后 practical
    + volumetric haze + HDRI studio reflection
```
- **写实生物**：`overcast soft key + GI + subtle rim + light atmospheric haze`
- **科幻内景**：`practical emissive panels + volumetric fog + hard cyan rim + ray-traced reflections`
- **产品 hero**：`top softbox + two strip lights + black flags for falloff + no ambient spill`
- **三渲二**：`single directional key + two-tone hard shadow + flat ambient, no GI`

### 联动规则
- **GI/光追 = 写实专属**：三渲二绝不能开，否则赛璐璐感被洗掉（见 12 禁止组合表）。
- **体积光需要介质**：写 `volumetric light shafts` 必须同时给 `haze / fog / dust`，否则光柱无附着物不出现。
- **焦散需要透明材质**：`caustics` 只在有 `glass / water` 时写。
- **产品片压环境光**：加 `controlled falloff, no ambient spill`，否则背景发灰。

## 06 动作运动（Motion Grammar）· 必选 · **本风格核心模块**

> CG 的运动由**物理与重量**驱动。判断一条 CG 视频好坏，看的不是动作多炫，而是「有没有质量感、有没有次级运动、惯性对不对」。

### 6.1 静态 / 微动作
- `idle breathing with chest rise and fall` — 待机呼吸
- `micro-sway to hold balance` — 维持平衡的微摆
- `slow blink with eyelid deformation` — 眼皮形变眨眼
- `fabric settling under gravity` — 布料重力沉降
- `dust slowly settling in the light beam` — 尘埃缓降
- `machinery idle vibration` — 机械怠速震动
- `turntable rotation at constant speed` — 匀速转台

### 6.2 动态 / 物理驱动动作
- `weighty step with ground compression` — 有重量的踏步压地
- `inertia carry-through after stopping` — 停止后惯性继续
- `overlapping action: body leads, appendages follow` — 重叠动作
- `secondary motion in cloth, hair, antenna` — 次级运动（CG 灵魂）
- `squash and stretch on impact`（风格化专用）
- `rigid-body collision with accurate bounce` — 刚体碰撞
- `fracture and shatter with debris spread` — 破碎与碎块扩散
- `FLIP fluid splash with whitewater` — 流体飞溅
- `smoke and pyro plume rising with turbulence` — 烟火湍流
- `cloth tearing along a seam` — 布料撕裂
- `soft-body jiggle deformation` — 软体抖动
- `muscle flex and skin sliding over bone` — 肌肉滑动
- `mechanical panel unfold in sequence` — 机械逐段展开
- `thruster ignition with heat distortion` — 推进器点火热扰

### 6.3 摄影机运动
- `slow gimbal push-in` — 稳定器缓推
- `technocrane arc reveal` — 摇臂弧线揭示
- `drone flythrough between obstacles` — 无人机穿障
- `oner: continuous single take through the space` — 一镜到底
- `parallax slide to reveal depth` — 平移视差
- `orbit turntable around subject` — 环绕
- `camera passes through glass / water surface` — 穿越透明界面（CG 招牌）
- `crash-in to macro detail` — 冲入微距
- `stabilized tracking follow` — 跟拍
- `motion-control repeat pass` — 可重复轨迹（合成用）

### 6.4 时间控制（Timing / Easing）
- `ease-in-out on all camera moves` — 机位全程缓入缓出（CG 高级感来源）
- `constant-velocity turntable, no easing` — 转台匀速无缓动
- `slow motion at 240fps equivalent` — 慢镜（模拟展示标配）
- `speed ramp from slow-mo into real-time` — 速度斜坡
- `time-lapse growth / accumulation` — 延时生长
- `frozen moment, camera keeps moving` — 时间静止但机位继续（bullet-time）
- `pose-to-pose snappy timing`（风格化）vs `straight-ahead smooth`（写实）
- `follow-through delayed by 3–5 frames` — 跟随动作延迟帧数

### 6.5 过渡 / 转场
- `match cut through a reflective surface` — 反射面匹配剪辑
- `camera dives into a light source, white transition` — 冲入光源转场
- `morph between two assets with topology blend` — 资产形变过渡
- `dissolve through volumetric fog` — 穿雾溶解
- `scale transition: macro to cosmic` — 尺度跨越转场
- `hard cut on impact frame` — 撞击点硬切

### 6.6 循环
- `seamless loop turntable, 360 degrees exactly` — 精确 360° 循环
- `looping simulation with steady state` — 稳态模拟循环

### 运动速查表：目的 → 运动配方

| 目的 | 机位 | 主体运动 | Timing | 关键补充 tag |
|---|---|---|---|---|
| 展示材质 | 微距慢滑 | 极微动 | 匀速 | `shallow DoF, accurate reflection` |
| 展示体量 | drone 缓升 | 缓慢踏步 | ease-in-out | `ground compression, dust puff` |
| 展示模拟 | 定机位 | 流体/破碎 | slow motion | `whitewater foam / debris spread` |
| 角色表演 | 微手持 MCU | 表情 + 次级运动 | pose-to-pose | `overlapping action` |
| 空间感 | oner flythrough | 环境动 | 匀速 ease | `parallax layers, volumetric fog` |
| 产品 | motion control | turntable | 匀速 | `no wobble, seamless loop` |
| 冲击力 | crash-in | 碰撞破碎 | speed ramp | `impact frame, camera shake` |

### 联动规则（硬约束）
- **次级运动是 CG 的身份证**：任何角色/生物镜必须带 `secondary motion` 或 `follow-through`，否则输出像僵硬游戏动画。
- **一镜一模拟**：流体 + 破碎 + 烟火三选一，同时写会互相污染成糊状。
- **多物体交互 ≤2**：AI 视频里三个以上物体物理交互必穿模，请拆镜或用合成。
- **机位与主体不同时高速**：模拟镜建议 `locked-off camera`，让观众看清模拟本身。
- **慢镜要给倍率语义**：写 `slow motion, roughly 8x slower than real time` 比裸写 `slow motion` 稳定得多。
- **匀速 vs 缓动要写死**：产品 turntable 必须 `constant velocity, no easing`，角色机位必须 `ease-in-out`。

## 12 负向规则（Negative Prompt & Forbidden Combos）· 必选

### 12.1 通用负向词库（写实 CG 基础版）
```
cartoon, cel shading, toon shading, flat lighting, anime style,
plastic look, waxy skin, uncanny valley, dead eyes, mannequin face,
melting geometry, warped topology, interpenetrating mesh, floating parts,
low-poly, faceted surface, jagged edges, aliasing,
deformed anatomy, extra limbs, extra fingers, fused joints, broken proportions,
jelly physics, weightless motion, sliding feet, foot skating,
flickering, temporal jitter, boiling texture, morphing background,
blown-out highlights, muddy shadows, banding, noise, jpeg artifacts,
watermark, signature, text artifacts, UI overlay, subtitles
```

### 12.2 三渲二 / 风格化 CG 专用负向（**与上表不同，务必区分**）
```
photorealistic, ray tracing, global illumination, subsurface scattering,
PBR roughness variation, skin pores, micro-scratches, film grain, sensor noise,
soft gradient shadow, ambient occlusion contact darkening,
realistic hair strands, physically accurate lens flare
```

### 12.3 分场景追加负向

| 场景 | 追加负向 | 原因 |
|---|---|---|
| 流体模拟 | `jelly water, plastic water, sticky blob, low-res foam` | 水最容易变果冻 |
| 破碎模拟 | `uniform debris size, floating fragments, no gravity` | 碎块要有大小分布与重力 |
| 产品 CG | `dust, fingerprints, scratches, blurry reflection, distorted logo` | 商业片要洁净 |
| 数字人 | `mannequin skin, dead stare, symmetrical face, plastic hair` | 恐怖谷防线 |
| 硬表面机械 | `soft rounded blobs, melted panels, illogical mechanism` | 机械要功能可信 |
| 一镜到底 | `scene change, camera cut, teleporting objects` | 保证连续 |
| 三渲二 | 见 12.2 全量 | 防止被洗成写实 3D |

### 12.4 禁止组合表（Forbidden Combos）

| 禁止组合 | 后果 | 替代写法 |
|---|---|---|
| `toon shading` + `ray tracing / GI / SSS` | 三渲二被洗成塑料半写实 | 三渲二只留 `two-step toon ramp, hard shadow` |
| `photorealistic` + `Pixar style` | 半写实恐怖谷 | 二选一；卡通型写 `stylized, not photoreal` |
| `100mm macro` + `fast camera move` | 焦外糊成一团、无有效信息 | 微距只配极慢机位 |
| `deep focus f/11` + `复杂几何场景` | 全画面暴露拓扑融化 | 用浅景深掩护，或降低场景复杂度 |
| 流体 + 破碎 + 烟火同镜 | 模拟互相污染成灰糊 | 一镜一模拟 |
| ≥3 物体物理交互 | 必定穿模 | 拆镜 / 合成 |
| `slow motion` + `high shutter crisp` + `motion blur` 同写 | 快门语义矛盾，输出不稳 | 只写一套快门逻辑 |
| `volumetric light shafts` 但无 `haze/fog/dust` | 光柱不出现 | 必须补介质 |
| `caustics` 但场景无透明物 | 无效 tag 占位，稀释权重 | 删除 |
| `pristine showroom` + `edge wear / grime` | 材质描述自相矛盾 | 二选一 |
| `hand-drawn / boiling line` + 任何 CG tag | 管线冲突，线条脏 | 手绘请走 `04-handdrawn-手绘2D动画.md` |
| `clean digital render, zero grain` + `subtle sensor grain` | 直接矛盾 | 写实留 grain，产品/三渲二关 grain |

### 12.5 冲突避免清单
- **拓扑三件套**：`clean topology, solid geometry, no melting` 建议写进每条 CG prompt 的正向。
- **手部**：写实 CG 手部畸变最刺眼 → 规避手部特写，或 I2V 用参考图锁手。
- **文字/LOGO**：产品 CG 的品牌文字一律后期加，或用 Wan 2.7 的屏内文字能力。
- **「不是实拍」的声明**：想要干净 CG 感而非实拍感时，明写 `rendered 3D, not real footage, clean render`。
- **时长**：复杂模拟镜控制在 3–5s；>8s 的 flythrough 走 Sora 2。
