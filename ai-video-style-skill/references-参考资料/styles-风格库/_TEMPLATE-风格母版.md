# 风格模块化模板（装配顺序分类法 / Modular Style Template）

> **用途**：本文件是所有风格条目的「母版」。每个风格（PV、CG、MG、手绘、AI 漫剧、商业、建筑、写真、NSFW 等）都按此 15 模块结构展开，深度对齐 `ShuaiHui/nsfw-prompt-templates-asian` 的「按装配顺序拆分 + 结构化词库 + 联动规则 + 禁止组合 + 装配公式」范式。
>
> **核心思想**：一张风格化视频的生成语义，按"组装顺序"拆成可索引的槽位；每个模块内部用 **词库 + 速查表 + 联动规则** 组织，强调 AI 易读性（小标题、索引表），而非自由散文。必选槽位固定，选读槽位每次随机 3–5 个。

---

## 0. 模块总览（每个风格文件都必须包含以下 15 节）

| # | 模块 | 作用 | 必选/选读 |
|---|------|------|-----------|
| 00 | 范例 | 3–5 条完整英文 prompt（含中文注释） | 必选 |
| 01 | 场景主题 | 子类型/题材/世界观锚点 | 必选 |
| 02 | 景别构图 | shot size / 角度 / 设备 / 焦段 / 构图 | 必选 |
| 03 | 主体特征 | 角色/物体设计、解剖、体型、特征 | 必选 |
| 04 | 服装造型 | 服饰、材质、状态 | 选读 |
| 05 | 光影氛围 | 布光、色温、情绪 | 必选 |
| 06 | 动作运动 | 运动语法（视频核心）→ 静态/动态/过渡 | 必选 |
| 07 | 表情表演 | 表情、眼神、表演阶段 | 选读 |
| 08 | 风格滤镜 | 美术方向、胶片/镜头、参考锚点 | 必选 |

## 1. 每个模块的写法规范

- **词库（vocabulary）**：用 `- ` 列表给出可直接嵌入 prompt 的英文 tag，附中文释义。
- **速查表（lookup）**：用表格给出「场景/子类型 → 推荐 tag 组合」「风格 → 模型」等映射。
- **联动规则（linkage）**：说明本模块 tag 与其他模块的约束（如"运动快→快门优先""裸体→排除 clothing tag"）。
- **禁止组合（forbidden）**：列出会冲突/翻车的组合（如"水墨风 + ray tracing 塑料感""写实 + toon shading"）。
- **示例（examples）**：每个风格至少 3 条完整英文 prompt，结构 = 场景主语 + 动作 + 镜头 + 光影 + 风格 + 材质 + 后期 + 负向。英文正文 + 中文行内注释。

## 2. 装配公式（通用骨架，各风格微调）

```
[00 范例]
[01 场景主题] + [02 景别构图] + [03 主体特征]
  + [05 光影氛围] + [06 动作运动] + [08 风格滤镜]
  + (选读 3–5 个: 04 服装 / 07 表情 / 09 材质 / 10 后期 / 11 道具)
  + [12 负向规则]
→ 推荐模型见 [13]
```

**必选槽位固定**：01 / 02 / 03 / 05 / 06 / 08 / 12 / 13 / 14。
**选读槽位随机取 3–5**：04 / 07 / 09 / 10 / 11。

---

## 3. 语言与硬规则（贯穿所有风格）

- 提示词正文用英文（多数视频模型英文效果最佳），配中文风格说明与注释。
- 非写实风格必须排除 `3D render / CGI / photorealistic / ray tracing` 等污染词（除非该风格本就含 3D）。
- 能用参考图 / 首尾帧就用：I2V 与首尾帧比纯文本一致性高得多。
- 涉及跨镜头叙事（漫剧/短剧）必须锁角色：参考图 + 首尾帧 + 角色表 + 拆 shot list。
- 禁止组合必须写入 12 节，避免 AI 把风格洗掉。
