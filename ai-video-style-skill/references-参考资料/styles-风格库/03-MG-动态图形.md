# 03 · MG — Motion Graphics（动态图形 / 会动的平面设计）

> **一句话定位**：不是「拍」出来的，是「设计 + 动效」出来的。主角是**图形、文字、数据、品牌元素**，不是人和世界。
>
> **核心矛盾（必读）**：主流「电影级」视频模型（Veo / Sora / Kling）在 MG 上**反而弱**——它们擅长拍真实世界，不擅长生成「绝对干净的矢量图形」。MG 的第一条决策不是写什么 prompt，而是**选对模型**（见 13 节）与**决定哪些部分交给 AE/PR 后期**。
>
> **与相邻风格的边界**：与 CG 区别在于 MG 不追求物理可信，追求**缓动曲线与版式节奏**；与 PV 区别在于 MG 无角色魅力叙事；与「字体动画」区别在于 MG 以图形为主、文字为辅（纯文字主角走排版动画）。
>
> **装配顺序**：01 → 02 → 03 →(04)→ 05 → 06 →(07)→ 08 →(09/10/11)→ 12 → 13 → 14。

---

## 00 范例（Examples · 完整英文 prompt）

> 结构 = 场景主语 + 动作 + 镜头 + 光影 + 风格 + 材质 + 后期 + 负向。中文为注释，投喂前删除。
> MG 的「场景主语」是图形系统，「光影」是渐变与辉光，「材质」是表面处理（扁平/玻璃/渐变）。

### 例 1 · Logo 粒子汇聚成形（品牌片头）
```
Thousands of small glowing dots swirl in a dark void and assemble into a clean          // 主体+动作
geometric logo mark, the final shape snapping into place with a slight overshoot,        // 动作+缓动
static centered composition, orthographic feel, no camera shake, subtle push-in at the end,// 镜头
deep navy background with a soft radial gradient, cyan glow emitting from the particles, // 光影
motion graphics, logo animation, minimal tech branding, flat vector aesthetic,           // 风格
clean vector shapes, crisp edges, no texture noise,                                      // 材质
additive glow bloom, slight lens vignette, smooth 60fps easing,                          // 后期
--no photorealistic, 3D render, film grain, noise, jitter, blurry edges, garbled text    // 负向
```

### 例 2 · 等距空间信息图（isometric explainer）
```
An isometric 2.5D city block of simple geometric buildings builds up piece by piece,     // 主体+动作

locked isometric camera at 30 degrees, slow lateral parallax slide, no perspective shift,// 镜头
flat ambient lighting with soft long shadows in a single direction,                      // 光影
motion graphics explainer, isometric flat design, corporate brand palette of blue and coral,// 风格
flat solid fills, subtle rounded corners, no gradients on shapes,                        // 材质

--no photorealistic, 3D render, ray tracing, texture, noise, perspective distortion, text// 负向
```

### 例 3 · 数据可视化生长（图表动画）
```
A bar chart grows from zero as glowing vertical bars rise in sequence,                   // 主体+动作
each bar eases out with a soft overshoot, a line graph draws itself left to right,       // 缓动
flat front-on composition, locked-off camera, slight scale-up at the reveal,             // 镜头
```

### 例 4 · Kinetic typography 卡点弹字
```
Bold sans-serif words pop onto the screen one after another in rhythm,                   // 主体+动作
each word scales up with a bounce and settles, previous words sliding out on a mask wipe,// 缓动+转场
```

### 例 5 · 抽象循环背景（loopable 素材）
```
Soft gradient blobs slowly morph and drift across the frame in a seamless loop,          // 主体+动作

full-frame abstract composition, no camera movement,                                     // 镜头
```

### 联动规则
- 选 `data visualization / infographic` → 12 必须加 `garbled numbers, wrong digits` 负向，且**数字建议后期加**。
- 选 `abstract loopable background` → 06 必须写 `seamless loop, identical first and last frame`，并优先用首尾帧模型。
- 选 `UI motion` → 08 建议锚 `Google Material motion` 或 `Apple keynote motion`，缓动才会「对味」。

## 02 景别构图（Framing / Camera / Layout）· 必选

> MG 的「镜头」多数时候是**版式**而非摄影机。真实摄影机语言在这里要克制——MG 里过多运镜 = 廉价。

### 取景 / 版式词库
- `full-frame graphic composition` — 满幅图形
- `centered symmetrical layout` — 居中对称（Logo 标配）
- `Swiss grid layout with strict alignment` — 瑞士网格严格对齐
- `rule-of-thirds editorial layout` — 编辑式三分
- `lower-third framing` — 下三分之一
- `split screen / diptych layout` — 分屏
- `card stack composition` — 卡片堆叠
- `screen-in-screen device mockup` — 设备样机内嵌屏
- `edge-to-edge safe margin respected` — 遵守安全边距
- `generous negative space` — 大量留白（高级感来源）

### 视角 / 投影词库
- `flat 2D front-on view` — 正面平视 2D
- `isometric 30-degree projection` — 30° 等距
- `dimetric / axonometric view` — 二测轴测
- `orthographic, no perspective distortion` — 正交无透视
- `subtle 2.5D depth with layered planes` — 微立体分层
- `top-down flat lay` — 正俯平铺

### 摄影机运动词库（克制使用）
- `locked-off, no camera movement` — 定机位（MG 默认）
- `slow push-in for emphasis` — 缓推强调
- `lateral parallax slide across layers` — 横向视差滑动
- `scale-up reveal (zoom out from detail)` — 由细节拉出
- `camera dolly through isometric space` — 穿越等距空间
- `rotate around a 2.5D stack` — 绕分层堆叠旋转

### 比例 / 输出词库
- `16:9 broadcast` / `9:16 vertical social` / `1:1 square feed`
- `4K crisp vector rendering` / `safe title area respected`

### 速查表：用途 → 版式配方

| 用途 | 版式 | 视角 | 机位 | 留白 |
|---|---|---|---|---|
| Logo 动画 | 居中对称 | 正面 2D | 定机位 + 末尾缓推 | 大 |
| 解释器 | 网格分区 | 等距 30° | 横向视差 | 中 |
| 数据看板 | 严格网格 | 正面 2D | 定机位 | 小 |
| 社媒竖屏 | 上下堆叠 | 正面 2D | 微推 | 中 |
| 播出包装 | 下三分之一 | 正面 2D | 定机位 | 大 |
| 产品标注 | 分屏 | 2.5D 分层 | 缓推 | 中 |

### 联动规则（重要）
- **MG 默认定机位**：写 `locked-off, no camera movement` 能显著提升图形稳定度；运镜越多，扩散模型越容易让图形变形。
- **等距投影必须写死角度**：`isometric 30-degree, orthographic, no perspective distortion`，否则模型会加透视，等距感消失。
- **留白 = 高级感**：`generous negative space` 是 MG 最便宜的质感提升 tag。
- **竖屏要重排版**：9:16 不要沿用 16:9 的横向网格，改 `vertically stacked layout`。
- **不要写摄影焦段**：`85mm / f/1.8 / bokeh` 会把 MG 拉向实拍质感，与扁平设计冲突。

## 03 主体特征（Graphic Elements / Subject）· 必选

> MG 的「主体」是图形系统。要像描述角色一样把图形的形态、构成、层级写清楚。

### 基础图形词库
- `simple geometric primitives: circles, squares, triangles` — 基础几何
- `rounded rectangles with consistent corner radius` — 统一圆角矩形
- `thin stroke outlines with uniform weight` — 等粗描边
- `filled solid shapes with no outline` — 纯色无描边填充
- `line art icons on a consistent grid` — 网格化线性图标
- `abstract organic blobs` — 有机流体形状
- `polygonal low-poly shapes` — 低多边形（风格化）
- `dot matrix / halftone pattern` — 点阵/半调
- `grid of evenly spaced elements` — 等距网格阵列
- `concentric rings and radial spokes` — 同心圆与辐条

### 结构 / 系统词库
- `modular design system, consistent visual language` — 模块化设计系统
- `hierarchy: primary shape dominant, secondary supporting` — 主次层级
- `foreground graphics / midground type / background gradient` — 三层结构
- `mask and reveal layers` — 遮罩层
- `duplicated element array with offset` — 阵列偏移复制
- `symmetry with a single deliberate break` — 对称中的一处破格

### 文字元素词库（作为图形的一部分）
- `bold sans-serif display type` — 粗无衬线大字
- `condensed grotesque headline` — 窄体无衬线标题
- `monospaced technical labels` — 等宽技术标签
- `serif editorial subhead` — 衬线编辑体副标
- `short single word only` — 只放单词（降低乱码风险）
- `numbers as large graphic elements` — 数字作为图形

### 品牌 / 色板词库
- `brand color palette: two primary + one accent` — 双主色 + 单强调色
- `monochrome with a single accent color` — 单色 + 强调色
- `duotone treatment` — 双色调
- `limited palette of three colors maximum` — 最多三色
- `high-contrast complementary pair` — 高对比互补色

### 联动规则
- **图形数量 ≤5 类**：MG 的干净来自克制；元素类型多了模型会把它们糊成噪点。
- **色板必须写死**：不写具体颜色，模型会给随机杂色，品牌感全无。写成 `deep navy #背景, electric cyan accent`。
- **文字越少越好**：一屏 ≤3 个单词；长句必然乱码（除非用 Wan 2.7 或后期）。
- **统一圆角/描边粗细**：`consistent corner radius, uniform stroke weight` 是「设计感」而非「AI 感」的关键。

## 04 表面处理 / 材质风格（Surface Treatment）· 选读

> MG 的「服装造型」等价于图形的表面处理。

- `flat solid fills, no gradient` — 纯扁平
- `subtle linear gradient fills` — 轻线性渐变
- `gradient mesh with soft color blending` — 渐变网格
- `glassmorphism: frosted blur with translucent panels` — 玻璃拟态
- `neumorphism: soft extruded shadows on a matching background` — 新拟态
- `neon stroke with outer glow` — 霓虹描边
- `chrome / liquid metal reflective surface` — 液态金属
- `matte paper texture overlay` — 纸质纹理
- `fine grain noise overlay for depth` — 细颗粒噪点（现代渐变标配）
- `dotted halftone shading` — 半调网点
- `outline-only wireframe style` — 纯线框
- `duotone photographic fill inside shapes` — 形状内嵌双色照片

### 速查表：表面处理 → 适用子类型

| 表面处理 | 适用 | 慎用于 |
|---|---|---|
| flat solid | 解释器、图标 | 高端品牌片（略单薄） |
| gradient mesh | 抽象背景、科技 | 数据图表（干扰读数） |
| glassmorphism | 仪表盘、UI | 印刷向输出 |
| neumorphism | UI 控件 | 深色高对比场景 |
| neon glow | 科技、游戏 | 企业稳重风 |
| liquid chrome | Y2K、潮牌 | 信息图（反光遮字） |
| grain overlay | 现代渐变风 | 需要极致干净的矢量 |

### 联动规则
- `flat solid fills` 与 `gradient mesh` 互斥，同写会得到脏色。
- `fine grain noise` 与 12 节的 `no noise` 负向直接冲突 —— 要颗粒就把 `noise` 从负向里删掉，改为 `no jpeg artifacts`。
- `glassmorphism` 需要背景有内容才看得出来 → 必须配 `colorful gradient background behind panels`。

## 05 光影氛围（Light / Color / Mood）· 必选

> MG 里没有真实光源，只有**渐变、辉光、投影**三件事。写法与实拍完全不同。

### 「布光」技法词库（图形化）
- `flat ambient lighting, no directional light` — 全平光（扁平设计默认）
- `soft long shadow in a single consistent direction` — 单向长投影（等距标配）
- `subtle drop shadow for card elevation` — 卡片抬升投影
- `inner shadow for inset elements` — 内阴影
- `outer glow / additive bloom on emissive shapes` — 外发光
- `radial gradient background, brighter at center` — 中心亮径向渐变
- `linear gradient wash from top to bottom` — 线性渐变底
- `spotlight vignette to focus attention` — 聚焦暗角
- `emissive neon shapes lighting the backdrop` — 霓虹自发光染背景
- `backlit frosted panel` — 背光磨砂面板

### 色彩 × 情绪速查表

| 配色 | 英文 tag | 情绪 / 行业 | 典型用途 |
|---|---|---|---|
| 深蓝 + 青 | `deep navy background, electric cyan accent` | 科技、可信 | SaaS、数据看板 |
| 白 + 单色 | `clean white background, single brand accent` | 简洁、企业 | 解释器、演示 |
| 黑 + 荧光 | `black background, neon lime and magenta` | 潮、娱乐 | 社媒、游戏 |
| 米 + 橘棕 | `warm beige and terracotta palette` | 温暖、生活方式 | 品牌故事 |
| 紫 + 粉渐变 | `purple to pink gradient mesh` | 梦幻、AI 感 | 产品发布 |
| 高对比黑黄 | `black and electric yellow, high contrast` | 醒目、警示 | 标题、卡点字 |
| 灰阶 + 单红 | `grayscale with a single red accent` | 编辑、克制 | 杂志式动效 |
| 粉彩多色 | `soft pastel multi-color` | 友好、教育 | 儿童/教学 |

### 组合公式
```
[背景渐变] + [图形填充色] + [强调色] + [投影/辉光处理]
例：radial navy gradient background + flat white shapes + electric cyan accent
    + soft outer glow on the accent elements only
```
- **科技看板**：`dark gradient bg + glassmorphism panels + neon cyan glow + faint grid`
- **企业解释器**：`white bg + flat brand-color shapes + single-direction long shadow`
- **社媒潮流**：`black bg + duotone shapes + heavy neon glow + grain overlay`

### 联动规则
- **辉光只给强调元素**：`glow on the accent elements only`，全屏发光会糊掉版式。
- **投影方向必须统一**：`single consistent shadow direction`，否则等距场景立刻穿帮。
- **暗底更容易出效果**：AI 模型在深色背景 + 发光图形上的成功率显著高于纯白背景上的细线条。
- **不要写色温**：`3200K / golden hour` 属实拍语言，会把 MG 拉回摄影质感。

## 06 动作运动（Motion Grammar）· 必选 · **本风格核心模块**

> MG 的运动由**缓动曲线（easing）+ 节奏（timing）+ 遮罩（mask）** 驱动。这是与 PV（节拍驱动）、CG（物理驱动）的根本差别。写 MG prompt 时，**缓动词比动作词更重要**。

### 6.1 静态 / 待机运动
- `subtle idle float, elements drifting slowly` — 元素轻微浮动
- `slow ambient gradient shift` — 渐变缓慢流动
- `gentle breathing scale pulse` — 呼吸式缩放脉冲
- `looping rotation at constant speed` — 匀速旋转
- `barely-there parallax drift` — 极轻视差漂移

### 6.2 入场 / 出场（Entrance / Exit）
- `fade in with slight upward drift` — 淡入上浮
- `scale up from zero with overshoot` — 由零放大过冲
- `slide in from off-screen edge` — 边缘滑入
- `mask reveal wiping left to right` — 遮罩左右擦出
- `clip-path circular reveal expanding` — 圆形裁切扩张
- `staggered entrance, elements appear 3 frames apart` — 错峰入场
- `assemble from scattered particles` — 粒子汇聚成形
- `unfold / accordion expand` — 展开折叠
- `type-on, character by character` — 逐字打出
- `pop out and dissolve into particles` — 弹出后粒子消散

### 6.3 变换 / 形变（Transform & Morph）
- `shape morph from circle to square with smooth interpolation` — 形状插值形变
- `path morph along a bezier curve` — 沿贝塞尔路径形变
- `liquid blob merge and split (metaball)` — 液态融合分裂
- `elastic stretch and snap back` — 弹性拉伸回弹
- `rotate on its own axis with easing` — 自转带缓动
- `flip 180 degrees to reveal the back face` — 翻转揭示背面
- `extrude flat shape into 2.5D depth` — 平面挤出立体
- `grid cells cascading like a wave` — 网格波浪级联
- `number counter rolling up` — 数字滚动计数
- `chart bars growing from baseline` — 图表由基线生长
- `line graph drawing itself with a stroke reveal` — 折线自绘

### 6.4 缓动曲线（Easing）· **MG 的灵魂，必写**
- `ease-in-out, smooth acceleration and deceleration` — 标准缓入缓出
- `ease-out with a sharp start and soft landing` — 急起缓停（最常用）
- `overshoot then settle back` — 过冲回弹
- `bounce on landing` — 落地弹跳
- `elastic wobble decay` — 弹性衰减
- `snappy linear for technical precision` — 线性精确（数据/UI）
- `anticipation dip before the move` — 移动前反向预备
- `staggered offset timing across elements` — 元素间错峰
- `exponential ease for a premium feel` — 指数缓动（高级感）
- `constant velocity for loops` — 循环用匀速（防接缝）

### 6.5 转场（Transition）
- `shape wipe transition with a growing circle` — 圆形扩张擦除
- `mask wipe along a diagonal` — 对角遮罩擦除
- `whip-pan style graphic smear` — 图形拖影甩场
- `color flash cut` — 色块闪切
- `element carries over into the next scene (match transform)` — 元素承接匹配转场
- `page turn / card flip` — 翻页/翻卡
- `liquid morph transition between scenes` — 液态形变转场
- `zoom-through a shape into the next frame` — 穿越图形转场
- `stripe wipe / venetian blind` — 条纹百叶擦除

### 6.6 节奏与循环（Rhythm & Loop）
- `beat-synced element pops, one per beat` — 每拍一弹
- `rhythmic grid pulsing to a steady tempo` — 网格节奏脉动
- `seamless loop, first and last frame identical` — 无缝循环
- `continuous scrolling marquee loop` — 滚动跑马灯
- `cycle of 4 elements repeating` — 四元素循环
- `hold for 12 frames before the next beat` — 停顿帧数

### 运动速查表：目的 → 运动配方

| 目的 | 入场 | 缓动 | 转场 | 循环 |
|---|---|---|---|---|
| Logo 揭示 | 粒子汇聚 | overshoot then settle | 末尾定格 | 否 |
| 解释器分步 | 错峰滑入 | ease-out | 元素承接 | 否 |
| 数据生长 | 由基线生长 | ease-out 无过冲 | 无 | 否 |
| 卡点字幕 | scale pop | bounce | 色块闪切 | 否 |
| UI 演示 | mask reveal | material ease-in-out | 页面推移 | 否 |
| 抽象背景 | 淡入 | 匀速 / 有机缓动 | 无 | 是 |
| 转场素材 | 形状扩张 | snappy linear | 本身即转场 | 否 |

### 联动规则（硬约束）
- **必须显式写缓动词**：只写 `the shape appears` 模型会给线性生硬运动；写成 `scales up with an ease-out overshoot` 才有设计感。
- **错峰是专业感来源**：多元素入场一律加 `staggered timing, elements offset by a few frames`，同时入场 = 业余。
- **循环必须首尾同帧 + 匀速**：`seamless loop, constant velocity, identical first and last frame`，任何 easing 都会造成接缝跳变。
- **一镜一主运动**：MG 里同时写「形变 + 转场 + 相机推进」会让图形崩坏；拆成多段后期拼。
- **数据类禁止 overshoot**：图表过冲会造成「数值超过真值」的错觉，写 `ease-out, no overshoot`。
- **卡点交给后期**：多数模型无法精确对拍，建议生成「单段动效 + 匀速」后在 AE/PR 按拍点裁切。
- **AI 生成的动效更适合做「氛围层」**：精确的 Logo/数据动画建议用 AE 做，AI 负责背景、粒子、抽象层。

## 07 「表演」/ 情绪节奏（Personality & Pacing）· 选读

> MG 没有角色表情，但图形有「性格」。这一槽位描述动效的人格化调性。

### 性格词库
- `playful and bouncy personality` — 活泼弹性（消费品牌）
- `precise and technical, minimal flourish` — 精确克制（B 端/金融）
- `premium and unhurried, slow exponential easing` — 高端从容（奢侈品/Apple 风）
- `energetic and punchy, fast snappy cuts` — 高能干脆（社媒）
- `calm and meditative, slow organic drift` — 冥想舒缓（健康/冥想类）
- `quirky and irregular, unexpected timing` — 古怪不规则（创意机构）

### 节奏阶段（三段式）
- `beat 1: anticipation — a small dip or hold` — 预备
- `beat 2: action — the main transform` — 主动作
- `beat 3: settle — overshoot resolves, micro-drift begins` — 沉降

### 联动规则
- `premium and unhurried` 与 `fast snappy cuts` 互斥；先定调性再选缓动。
- B 端/金融类禁止 `bounce / elastic`，会显得不严肃 → 用 `ease-out, no overshoot`。

## 12 负向规则（Negative Prompt & Forbidden Combos）· 必选

### 12.1 通用负向词库（MG 基础版）
```
photorealistic, realistic photo, live-action footage, 3D render, ray tracing,
cinematic lighting, film grain, sensor noise, lens dirt, bokeh, depth of field blur,
blurry edges, soft mushy shapes, uneven stroke weight, inconsistent corner radius,
jagged aliasing, pixelation, banding, jpeg artifacts,
garbled text, misspelled words, nonsense letters, wobbling glyphs, warped typography,
random extra shapes, cluttered composition, asymmetric misalignment,
flickering, temporal jitter, morphing background, shape drift,
human figures, faces, hands, animals, natural landscapes,
watermark, signature, timecode, UI chrome
```

### 12.2 分场景追加负向

| 场景 | 追加负向 | 原因 |
|---|---|---|
| Logo 动画 | `distorted logo, asymmetric mark, extra strokes` | Logo 变形 = 品牌事故 |
| 数据可视化 | `wrong numbers, garbled digits, inconsistent scale, overshoot` | 数值必须可信 |
| 等距解释器 | `perspective distortion, inconsistent shadow direction, vanishing point` | 等距必须正交 |
| Kinetic type | `misspelled text, letter swapping, wobbling baseline` | 文字是主角 |
| 抽象循环 | `scene change, hard cut, objects, characters, text` | 保证可循环 |
| 企业 / 金融 | `bounce, elastic wobble, glitch, neon, playful` | 调性不符 |
| 纯净矢量风 | `grain, noise, texture overlay, paper fiber` | 与 09 路线绑定 |
| 复古 VHS / risograph | **删除** `noise / grain` 负向 | 否则自相矛盾 |

### 12.3 禁止组合表（Forbidden Combos）

| 禁止组合 | 后果 | 替代写法 |
|---|---|---|
| `flat design` + `ray tracing / global illumination` | 扁平被渲染成塑料 3D，设计感尽失 | 只写 `flat ambient lighting, no directional light` |
| `clean vector shapes` + `film grain / noise overlay` | 边缘被噪点吃掉，不再是矢量感 | 二选一；要颗粒就同步改 12.1 |
| `isometric` + `85mm lens / depth of field` | 加入透视与虚化，等距立刻失效 | 写 `orthographic, no perspective, deep focus` |
| `long sentence of on-screen text` + 任何 T2V 模型 | 必然乱码 | 一屏 ≤3 词，或用 Wan 2.7，或后期加字 |
| `overshoot / bounce` + `data visualization` | 数值视觉上超过真值，误导 | `ease-out, no overshoot` |
| `seamless loop` + `ease-in-out` | 首尾速度不匹配，循环有跳变 | `constant velocity` |
| 形变 + 转场 + 推镜同镜 | 图形结构崩坏成噪点 | 一镜一主运动 |
| `glassmorphism` + 纯色平背景 | 磨砂效果不可见，白做 | 背景改 `colorful gradient` |
| `Apple keynote premium` + `Memphis playful bounce` | 调性冲突，四不像 | 锚点 1 主 1 副且同调性 |
| `photorealistic product` + `flat vector` | 两种质感在同帧打架 | 产品实拍层后期合成 |
| 用 Veo / Sora 硬做精确 Logo 动画 | 图形不干净、模型不擅长 | 换 Animora MotionVid 或 AE |

### 12.4 冲突避免清单
- **文字策略（最重要）**：
  1. 首选后期 AE/PR 加字（100% 可控）；
  2. 必须模型出字 → 用 **Wan 2.7**（屏内可读文字，12 国语言）；
  3. 无论如何，一屏 ≤3 个单词，用粗无衬线，避免小字号与长句。
- **干净度策略**：正向写 `crisp anti-aliased vector edges, clean flat shapes`，负向写 `blurry edges, noise, grain`。
- **模型策略**：精确图形交 AE / Animora，AI 负责抽象层、粒子层、渐变背景层，再合成。
- **循环策略**：用首尾帧模型（Wan 2.7 / Vidu Q3）做 loop，纯 T2V 很难首尾闭合。
- **不要用摄影语言**：焦段、光圈、色温、胶片型号一律不写。

## 13 推荐模型（Model Mapping）· 必选

> 模型能力口径见 `../models-模型能力矩阵.md`。**MG 是唯一一个「顶级通用模型反而不推荐」的风格。**

### 主推

| 模型 | 定位 | 为何契合 MG |
|---|---|---|
| **Animora MotionVid** | **MG 专精，第一选择** | 动态图形 / 动画赛道专精（intro、解释器、logo 动画），是少数针对「设计感图形」而非「真实世界」训练的方案；大多数电影级模型在此反而弱 |
| **Wan 2.7** | 屏内可读文字 + 首尾帧 | **12 国语言屏内文字**是 MG 的刚需能力；首尾帧可做精确 loop；风格化艺术表现好；开源可自部署，便于批量出素材 |
| **Runway Gen-4** | 精控运动 / v2v | 运动笔刷可指定「哪块图形怎么动」，对 prompt 内运镜指令响应好；v2v 可把 AE 粗稿升级为风格化动效 |
| **Pika** | 特效实验 / 快速试错 | 界面最简、特效有趣、prompt 实验友好，适合快速探抽象动效方向 |

### 备选 / 专项

| 需求 | 模型 | 理由 |
|---|---|---|
| 抽象渐变背景 / 有机形变 | **Luma** | 输出干净无伪影，适合柔和抽象层 |
| 2.5D 挤出 / 立体图形 | **MiniMax H3** | 风格化强，液态/流体形变（metaball 类）表现好 |
| 竖屏社媒 MG 卡片 | **PixVerse v5.6** | 竖屏友好、快、便宜，适合批量社媒物料 |
| 高分辨率大屏 / 数字标牌 | **LTX** | 开源 4K@50fps、20s、原生竖屏 |
| 风格化实验补充 | **Hunyuan** | 作为风格化生成的备选管线 |
| 需要写实产品与图形混合 | **Kling 3.0** / **Seedance 2.0** | 只用于「实拍质感层」，图形层仍交 AE |

### ⚠️ 不推荐（反向指引）

| 模型 | 为何不适合 MG |
|---|---|
| **Veo 3.1** | 强项是电影级写实与音画同步，生成「干净矢量图形」时会加入摄影质感与噪点 |
| **Sora 2** | 强项是叙事连贯与时序物理，MG 无叙事无物理，能力错配 |
| **Kling O03** | 极致保真面向真实世界材质，对扁平设计无增益 |
> 结论：这三者可用于 MG 片子里的**实拍插入镜**，但不要用来生成图形本体。

### 工作流建议（MG 专用「三层法」）
1. **图形层（精确）** → AE / Figma / Animora 做 Logo、文字、图表，保证 100% 可控；
2. **氛围层（AI）** → 用 Wan 2.7 / Luma / Pika 生成渐变背景、粒子、抽象形变；
3. **升格层（AI）** → 用 Runway Gen-4 的 v2v / 运动笔刷把粗稿风格化；
4. 在 AE/PR 合成 + 卡点 + 加字 + 统一调色。
