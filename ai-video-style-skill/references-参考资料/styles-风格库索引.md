# 视频 / 美术风格库（Style Library · 索引 + 装配公式）

本文件是「AI 视频提示词工程 + 模型选择」skill 的核心入口。每个风格已**拆分为独立的模块化文件**（位于 `references-参考资料/styles-风格库/`），统一遵循 `_TEMPLATE-风格母版.md` 的 **15 模块装配顺序分类法**（深度对齐 [`ShuaiHui/nsfw-prompt-templates-asian`](https://github.com/ShuaiHui/nsfw-prompt-templates-asian) 的范式）。

> **装配顺序分类法（Assembly-Order Taxonomy）**：把生成一张风格化视频所需的语义，按"组装顺序"拆成可索引槽位；每个模块内部用 **词库 + 速查表 + 联动规则** 组织，强调 AI 易读性。必选槽位固定，选读槽位每次随机 3–5 个。

## 通用装配公式（Universal Assembly）

```
[01 场景主题] + [02 景别构图] + [03 主体特征]
  + [05 光影氛围] + [06 动作运动] + [08 风格滤镜]
  + (选读 3–5 个: 04 服装 / 07 表情 / 09 材质 / 10 后期 / 11 道具)
  + [12 负向规则]
→ 推荐模型见 [13]
```

**必选槽位固定**：01 / 02 / 03 / 05 / 06 / 08 / 12 / 13 / 14。
**选读槽位随机取 3–5**：04 / 07 / 09 / 10 / 11。

## 硬规则（贯穿所有风格）

- 提示词正文用英文（多数视频模型英文效果最佳），配中文风格说明与注释。
- 非写实风格必须排除 `3D render / CGI / photorealistic / ray tracing` 等污染词（除非该风格本就含 3D）。
- 能用参考图 / 首尾帧就用：I2V 与首尾帧比纯文本一致性高得多。
- 涉及跨镜头叙事（漫剧/短剧）必须锁角色：参考图 + 首尾帧 + 角色表 + 拆 shot list。
- **>10 秒 / 卡点 / 多动作**：用 `timestamp-storyboard-秒级分镜法.md` 秒级分镜法，别写一段模糊长 prompt。
- **要声音/对白/配乐**：按 `sound-design-声音设计.md` 指挥声场与音画同步；原生音频模型（Veo 3.1 / Kling 3.0 / MiniMax H3 / Seedance 2.0）可直接写声场，其余后期配。
- **出提示词前过 `creativity-gate-创意闸门.md` 四关**（记忆点/意外感/情绪/叙事），对抗平庸。
- **情绪戏/微表情**：按 `emotion-shot-情绪镜头设计.md` 做景别递进（MCU→ECU）与泪时机绑定运镜。
- **定美术方向**：优先用 `style-combos-风格组合.md` 的导演签名锚定（胡金铨/王家卫/张艺谋…），比泛写"中国风"命中率高。
- 禁止组合必须写入各风格 12 节，避免 AI 把风格洗掉。
- NSFW / 亚洲成人风格（09）结构严格对齐 `ShuaiHui/nsfw-prompt-templates-asian` 的 15 模块分类法；运行于闭源平台（平台自带审查，不做额外审核），以 I2V + 首尾帧 + 参考图锁人物为主。

## 如何新增一个风格（模板）

1. 复制 `references-参考资料/styles-风格库/_TEMPLATE-风格母版.md` → `references-参考资料/styles-风格库/NN-xxx.md`。
2. 按 00–14 节逐节填充：词库用 `- ` 列表、速查表用 markdown 表格、联动/禁止组合用明确条目。
3. 每个风格至少 3 条完整英文示例（含中文注释）。
4. 在第 13 节映射到 `models-模型能力矩阵.md` 的真实模型名；第 14 节给出本风格装配公式。
5. 在上方「风格索引」表登记，并同步更新 `decision-matrix-决策映射.md` 的映射表与 `SKILL.md` 的覆盖声明。
